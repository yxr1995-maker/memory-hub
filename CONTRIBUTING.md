# Contributing to memory-hub

Thank you for contributing. Keep pull requests small, focused, and free of
private session data, credentials, local paths, generated reports, and runtime
artifacts.

Before opening a pull request, run the repository tests and `./memory-hub.sh
verify`. Add or update a focused regression test for behavior changes. Do not
commit `staging/`, `.omo/`, local research directories, or generated reports.

Use issues for bugs, feature proposals, and documentation discussions. Do not
report security vulnerabilities in public issues; follow [SECURITY.md](SECURITY.md).
