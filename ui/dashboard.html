流水线与维护命令速查

一键全链路闭环 (Run)
bash memory-hub.sh run

默认以 auto=on, apply=on, commit=on 依次执行 capture → distill → scope-backfill → successor → publish → index → archive

跨日聚类与知识库维护 (Maintain)
bash memory-hub.sh maintain

执行 7 阶段事务：validate → publish_pages_lifecycle → index_swap → lint → manifest_commit → archive → exact_stage_commit

安全只读仿真 (Safe Simulation)
bash memory-hub.sh run --safe

执行所有规划与校验，但对 wiki 文件、manifest 与 Git 零写入

确定性 Scope 批量回填
bash memory-hub.sh scope-backfill --apply

按 6 级确定性规则分批回填存量约 12,900 Markdown 页面
